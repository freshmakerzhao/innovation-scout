## 发现的问题与修正

1. **原始长问题导致 OpenAlex 请求返回 400。** 增加英文短关键词规划，也支持 `--keywords` 手动指定；摘要文档模式不再重复拿长问题做联网搜索。
2. **全文抓取受当前网络影响。** 本机将部分论文域名解析到 `198.18.*` 代理地址，上游 URL 安全检查拒绝抓取。保留原安全检查，明确使用 OpenAlex 已返回的摘要作为证据，不声称读取了全文。
3. **无资料说明被 CLI 当作成功报告保存。** 现在检查至少两篇可用摘要和非空研究上下文；没有证据时失败并记录原因。
4. **引用需要核对。** 正文必须包含证据清单中的 URL，出现清单外链接时拒绝作为成功报告保存。兼容中文标点与代码格式包裹的链接；未通过草稿保存为 `.rejected.md` 供排查。一次中间复测被该检查拒绝，当时未保存原始草稿，不能追溯断言是格式差异还是模型补写链接。
5. **上游美元估算不等于 MiMo 账单。** 新增基于模型实际返回 token 和缓存命中的人民币估算，保存在本次任务的证据文件中。

人工抽查了生成报告与所引摘要：杨氏模量约 20 GPa、浆料溶剂/电解质/粘结剂极性失配等表述可以在摘要中找到依据。此抽查不等于全文审查，也不能证明每条推断正确。报告保留了证据范围和未知项。
