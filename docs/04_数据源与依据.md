# 数据源、使用条件与调研依据

核对日期：2026-09-24。接口、额度、价格和许可证会改变，实际连接前由数据负责人逐项复核并记录版本。下列“首期接入”是方案，并不表示账户或数据授权已经取得。

## 首期数据源

| 来源 | 计划用途 | 当前依据与边界 | 实施前动作 |
| --- | --- | --- | --- |
| [OpenAlex API](https://help.openalex.org/api/) | 论文、作者、机构、主题等学术元数据和增量发现 | [认证说明](https://help.openalex.org/api/authentication/)称可匿名少量访问，规模化建议免费 key；接口返回配额信息，需处理 429 和游标分页。[价格页](https://help.openalex.org/access/pricing/)说明免费 key 每日有用量预算，超额另计。开放元数据不等于取得论文全文处理权。 | 机构注册 key；W1 用真实主题记录 API 成本、覆盖和上游延迟 |
| [EPO Open Patent Services](https://www.epo.org/en/searching-for-patents/data/web-services/ops) | 专利著录、家族、法律事件及适用全文字段 | 需注册/OAuth；当前免费阈值为每周 4 GB。[条款](https://www.epo.org/en/service-support/ordering/terms-and-conditions/ops-terms-and-conditions)允许用于自有产品，但限制把原始数据作为数据集再公开分发；[公平使用要求](https://www.epo.org/en/service-support/ordering/fair-use)规定自动查询方式和流量限制。法律状态只能作为核查线索。 | 注册并确认用途；W1 小样本验证地域覆盖、字段、更新延迟与配额 |
| [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | DOI 元数据补全和交叉核对 | 不作为全文源。Crossref 在 2025 年调整了公共/礼貌池限额，实施时按现行文档和响应头限速。 | 设置联系邮箱、缓存和退避；记录 API 版本 |
| 机构授权数据/手工导入 | 中文学位论文、地方政策、专家名录、企业需求 | 各机构的开放性、再使用权和保密要求不同；没有授权不批量抓取或导出全文。 | 获得字段级授权清单、样例和联系人；无稳定接口时用 CSV/Excel 导入 |

数据源质量卡需要记录：覆盖领域/地域、更新频率、可查询字段、标识符、全文权利、缓存与再分发条件、额度、费用、故障告警联系人和上次复核日期。

## 现有开源项目如何使用

| 项目 | 首期决定 | 依据 |
| --- | --- | --- |
| [GROBID](https://github.com/grobidOrg/grobid) | 在有权限的 PDF 上做解析组件，先对中文/英文样本测准确率 | 官方 README 列出作者、机构、全文结构、引用与专利引文提取；许可证 Apache-2.0 |
| [PaperQA2](https://github.com/Future-House/paper-qa) | 参考其证据检索与引用方式；是否嵌入代码在 W2 PoC 后决定 | 项目针对科学文献问答；大批量文档会涉及模型、Crossref 和 Semantic Scholar 服务 |
| [ASReview LAB](https://github.com/asreview/asreview) | 借鉴人工反馈筛选方法，不在首期运行独立综述系统 | 项目主流程是文献导入、人工标注与主动学习排序 |
| [PQAI](https://github.com/pqaidevteam/pqai) | 专利相似检索的对照基线；生产嵌入待独立部署和覆盖验证 | 项目说明其支持自然语言现有技术检索；若干拆分组件维护日期较旧 |
| [GPT Researcher](https://github.com/assafelovic/gpt-researcher) | 借鉴问题拆解与报告流程，不作为事实判断的唯一来源 | 项目自身声明为实验性应用 |
| [Open Targets](https://github.com/opentargets/platform-docs) | 借鉴领域本体与证据评分设计；不直接套用生物医药模型 | 官方范围是靶点—疾病等关联 |

关于这些项目的功能和维护记录，最初调研于 2026-09-24 完成；本项目重新整理了适用决策。首期技术选型按独立小范围试点设计，没有对上述组件做生产性能承诺。

## 待核实的关键事实

1. 目标产业方向及其最可靠的论文、专利、政策、专家来源。
2. 中文学位论文和高校成果库是否有机构合作接口；取得哪些字段与处理权。
3. EPO OPS 对试点地域、专利族及法律事件的覆盖是否满足业务；中国专利状态如何回到权威来源复核。
4. 外部模型能否接收公开摘要、授权全文或脱敏企业需求；数据出境与存储要求由机构确认。
5. 20 条企业真实需求及服务人员是否能在 W1 提供，决定匹配评估的实际意义。
