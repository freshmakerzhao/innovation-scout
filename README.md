# 科研情报与技术转移平台（方案项目）

创建日期：2026-09-24。此目录是独立的新项目，现阶段只放会议决策和实施文档，不依赖 BMG/IP 生成器工程，也没有已经运行的软件。

## 一句话目标

持续收集论文、专利和公开科技动态，形成可追溯的技术与团队线索，由服务人员核验后匹配企业需求和政府科技计划，并记录后续服务结果。

## 开会从哪里读起

1. [会议讨论稿](docs/00_会议讨论稿.md)：十分钟介绍、建议决策和待确认问题。
2. [产品范围与验收](docs/01_产品范围与验收.md)：首期做什么、谁来用、怎样算有效。
3. [技术架构与数据](docs/02_技术架构与数据.md)：技术栈、数据流、人工审核与安全边界。
4. [实施计划与资源](docs/03_实施计划与资源.md)：12 周日程、团队、软硬件、成本计算和风险。
5. [数据源与依据](docs/04_数据源与依据.md)：已核对的官方入口、使用条件和待办。
6. [会议决定记录](docs/05_会议决定记录.md)：会后填写并锁定首期范围。
7. [实施任务清单](docs/06_实施任务清单.md)：开发时可直接拆为独立任务的交付顺序。

示例记录格式：[机会卡](templates/机会卡模板.md)、[需求卡](templates/需求卡模板.md)。

## 估算前提

- 首期仅选 **一个产业方向、三个监测主题、约十名内部用户**；不承诺覆盖全球所有论文与专利。
- 试点目标容量：累计约 2 万篇论文元数据、5 千条专利元数据、2 千份有处理权限的全文或附件，每日新增不超过 500 条候选记录。
- 需要真实企业需求提供方、科技服务人员和领域专家参与；采购数据、模型与生产部署方案待会议确认。
- 以 **4 人左右的跨职能小组、从正式启动起 12 周**估算。单人开发、数据授权延迟或增加产业方向会改变工期。

这些数字是容量与排期假设，不是已有覆盖量或性能承诺。技术版本和数据服务价格在实施锁版、采购前重新核验。
