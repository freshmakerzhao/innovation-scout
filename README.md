## V0.1 的边界

- 一个产业方向、三个监测主题、1–3 位内部试用者；论文与专利元数据均可查，并保留原始链接。
- 每日增量线索、按需研究报告、可人工修改和批准的机会卡、少量真实需求的人工辅助匹配。
- 初期由现有模型 API 提供推理；无需本地 GPU。专利法律状态、可实施性和申报资格由专业人员核验。
- 首版内部受控访问；多机构权限、全量数据库、自动项目申报和生产高可用放到后续版本。

`app/` 保留上游原有许可证、版权和 README；对外分发或商用前还需核对其根 `LICENSE`（Apache-2.0）与 `pyproject.toml` 中的 MIT 标记不一致的问题，见[数据源与依据](docs/04_数据源与依据.md)。
